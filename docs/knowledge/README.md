# Chat Knowledge Base

Place trusted flood-risk, evacuation, and relocation guidance here as PDF, Markdown, or plain-text files. Prefer current publications from official agencies and retain the issuing organization, title, and publication date in each document.

The chat retrieves up to three keyword-relevant passages using BM25 and cites the source filename and, for PDFs, the page number. This is lexical retrieval, not embedding-based semantic search. Scanned PDFs require OCR before they can be searched. Restart the app after adding or changing documents.

## Included source

- `NDMA_Management_of_Floods_2008_FAO_Mirror.pdf` is the National Disaster Management Authority's *National Disaster Management Guidelines: Management of Floods* (2008). The file is mirrored by [FAOLEX](https://faolex.apps.fao.org/en/documents/LEX-FAOC216642/national-disaster-management-guidelines-management-of-floods); its original source is [NIDM](https://nidm.gov.in/). It covers flood preparedness, mitigation, forecasting, warning, and response planning. This is a historical guideline, not a live forecast, current alert, or confirmation of current Punjab procedures. Verify operational decisions against current official sources.
